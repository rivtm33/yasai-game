# 🍇 シャインマスカットゲーム

スイカゲーム風の落ちものパズル。もやしから始めて、同じ野菜どうしをくっつけながら
最高級の **シャインマスカット** を目指します。

▶ **あそぶ: https://rivtm33.github.io/yasai-game/**

外部ライブラリなし。物理エンジン・効果音・BGM・野菜の画像まで、すべて HTML 1枚に入っています。

---

## 進化ルート（8段階）

| # | 野菜 | 点 |
|---|------|----|
| 1 | もやし | 1 |
| 2 | きゅうり | 3 |
| 3 | なす | 6 |
| 4 | トマト | 10 |
| 5 | ブロッコリー | 15 |
| 6 | パプリカ | 21 |
| 7 | まつたけ | 28 |
| 8 | シャインマスカット | 36 |

シャインマスカット同士がくっつくと、2つとも消えて **+100点**。

| レベル | 落とせる野菜 | 大きさ | デッドライン | 猶予 |
|--------|--------------|--------|--------------|------|
| かんたん | もやし〜トマト | ×1.05 | 高め | 2.0秒 |
| ふつう | もやし〜なす | ×1.15 | 標準 | 1.2秒 |
| むずかしい | もやし〜なす | ×1.30 | 低め | 0.7秒 |

## 操作

- **クリック / タップ** … その位置に野菜を落とす
- **◀ ▶（画面の左右）** … カゴを横からゆさぶる“ずる”。詰まりをほぐせる
- **🔀 シャッフル** … 盤面をグラグラ揺らして、野菜の種類をシャッフル（回数無制限）
- **⏩ オート** … 高速で自動プレイ（重力2倍）
- **🔔 / 🎵** … 効果音・BGM の切り替え
- **🏆 ランキング** … 今日の何回目に何個できたかを記録

## ランキング

1プレイごとに「日付・その日の何回目・レベル・シャインマスカットの個数・スコア」を
ブラウザの localStorage に保存します。`ranking.html` で

- きょうの記録（何回目ごと）
- 歴代ベスト10（マスカットの数 → スコア順）
- 日ごとの合計

を表示します。記録はブラウザごとにローカル保存で、サーバーには送信されません。

## しくみ

- **物理**: Position Based Dynamics の自作実装（重力 → 積分 → 拘束解決7回 × 2サブステップ → 速度復元）
- **音**: Web Audio API でその場合成。BGM は 86BPM・4小節ループ、効果音は合体の段が上がるほど音程が上がる
- **画像**: 実写を円形に切り出して base64 で埋め込み
